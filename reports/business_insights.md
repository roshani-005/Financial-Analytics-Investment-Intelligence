# Business / Investment Analytics Insights

This project uses historical TSLA market data. It is an analytics project, not personalized investment advice.

## Questions answered
- How has the closing price changed over time?
- Which periods experienced the largest daily moves?
- When was rolling volatility highest?
- What were the largest observed drawdowns?
- How did monthly returns change over time?
- Can historical market features help predict the next trading day's close?

## Data limitation
The supplied file contains only Date, Open, High, Low, Close and Volume. It does not contain revenue, EBITDA, net income, EPS, market capitalization, P/E or EV/EBITDA. Those fundamental/valuation metrics are therefore not fabricated.

To extend this project into full fundamental investment analytics, add a verified company-fundamentals dataset keyed by ticker and reporting period.
